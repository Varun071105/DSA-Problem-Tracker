DSA Problem Tracker
This is a Python-based DSA Problem Tracker application that helps you log and visualize your problem-solving journey.

🧠 Features
Add problems with details like title, topic, difficulty, platform, status, and date solved.
Filter problems by topic or difficulty.
Track your progress with a summary of problems solved.
View data visually using a bar chart.
GUI version built with tkinter for easy interaction.
🧰 Tech Stack
Python 3
JSON (for storage)
Tkinter (for GUI)
Matplotlib (for charts)
🏁 How to Run
CLI Version:
python DSA_Problem_Tracker_Project.py
GUI Version:
python DSA_Problem_Tracker_GUI.py
✅ Sample Use Cases
Track problems solved daily.
View how many easy/medium/hard problems you've completed.
See which topics you are strong or weak in.
